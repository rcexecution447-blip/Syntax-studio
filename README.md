- **Jarvis System:** Respons cepat dan cerdas.

## 🛠️ Cara Instalasi (Cloud/Render)
1. Buat repository baru di GitHub.
2. Upload file `main.py` dan `requirements.txt`.
3. Di **Render.com**, buat **New Web Service**.
4. Gunakan Build Command: `pip install -r requirements.txt`.
5. Gunakan Start Command: `python main.py`.

## 📡 Perintah Bot

- `!syntax [permintaan]` -> Meminta AI membuatkan script, website, atau menjawab tugas.
